# Security

Run locally by default. This application is designed for a trusted single operator. Do not expose its initial bootstrap or localhost-trusted control routes to untrusted callers. Protect local configuration, generated notebooks and backups.

Never post tokens, account files, endpoint state or logs in issues. Revoke and replace any credential that was accidentally disclosed. Check the complete staged diff before publishing changes; ignore rules do not protect files already tracked.

Report suspected vulnerabilities privately to the repository maintainer through an available private contact or private security report, without posting exploit details or secrets publicly.
